## 一、系统功能介绍

本系统是一套完整的眼镜店管理软件，支持以下功能：

| 模块 | 功能说明 |
|------|----------|
| 📊 **仪表盘** | 今日营业额、订单数、会员数、库存预警、最近订单、最近验光 |
| 👥 **会员管理** | 会员增删改查、搜索、余额充值、积分累计、消费记录 |
| 📦 **库存管理** | 商品增删改查、分类管理（镜片/镜架/隐形眼镜/配件）、入库操作、库存预警 |
| 💰 **消费收银** | 商品选择、购物车、会员余额支付、现金/微信/支付宝、优惠折扣、二次确认 |
| 🔬 **验光管理** | 验光数据录入（左右眼球镜/柱镜/轴位/视力/瞳距）、黑白报告单打印 |
| 📋 **订单记录** | 订单列表、按日期/关键词筛选、退款删除（自动恢复库存和余额） |
| ⚙️ **系统设置** | 门店信息设置、数据备份下载、数据恢复导入 |

### 技术架构

- **后端**：Node.js + Express + SQLite（轻量数据库，无需额外安装数据库软件）
- **前端**：纯 HTML/CSS/JavaScript（无需编译，打开即用）
- **桌面端**：Electron 打包成 .exe 安装包
- **部署**：Render.com 免费云托管

## 二、本地运行测试

在部署到云端之前，建议先在自己电脑上运行测试，确认系统正常。

### 2.1 安装 Node.js

1. 打开浏览器，访问 https://nodejs.org/
2. 下载 **LTS（长期支持版）**，推荐 Node.js 18 或更高版本
3. 双击下载的安装包，一路点击"下一步"完成安装
4. 安装完成后，按 `Win + R`，输入 `cmd` 回车，打开命令提示符
5. 输入 `node -v`，如果显示版本号（如 `v18.17.0`），说明安装成功

### 2.2 启动系统

1. 将项目文件夹 `glasses-shop-system` 放到一个你记得住的位置（比如桌面）
2. 打开项目文件夹，在地址栏输入 `cmd` 然后回车（会在当前目录打开命令行）
3. 输入以下命令安装依赖（第一次运行需要，以后不需要）：
   ```
   npm install
   ```
   等待安装完成，可能需要 1-3 分钟。

4. 输入以下命令启动系统：
   ```
   npm start
   ```

5. 看到类似以下输出说明启动成功：
   ```
   ╔══════════════════════════════════════════════╗
   ║   👓 眼镜店管理系统 - 网络版 v1.0.0          ║
   ║   TT游戏工作室 & 豆包 联合开发                 ║
   ╠══════════════════════════════════════════════╣
   ║   🌐 服务器地址: http://localhost:3000         ║
   ╚══════════════════════════════════════════════╝
   ```

6. 打开浏览器，访问 **http://localhost:3000** 即可使用系统

> ⚠️ **注意**：这个命令行窗口不能关闭，关闭后系统就停止运行了。要停止系统，在命令行窗口按 `Ctrl + C`。

### 2.3 首次使用

系统首次启动会自动创建数据库并初始化一些示例数据（5个会员、15个商品、4条验光记录、3个订单），方便你测试。你可以直接使用，也可以在系统设置中导入自己的数据。

## 三、创建 GitHub 仓库并上传代码

Render 需要从 GitHub 拉取代码进行部署，所以我们需要先把代码上传到 GitHub。

### 3.1 注册 GitHub 账号

1. 访问 https://github.com/
2. 点击右上角 "Sign up" 注册账号
3. 用你的邮箱注册，设置用户名和密码
4. 注册完成后登录

### 3.2 安装 Git

1. 访问 https://git-scm.com/download/win
2. 下载 Windows 版 Git 安装包
3. 双击安装，一路点击 "Next" 使用默认设置即可
4. 安装完成后，重新打开一个命令行窗口，输入 `git --version`，显示版本号说明安装成功

### 3.3 创建 GitHub 仓库

1. 登录 GitHub 后，点击右上角的 `+` 号，选择 "New repository"
2. 填写仓库信息：
   - **Repository name**：输入 `glasses-shop-system`（或你喜欢的名字）
   - **Description**：可选，比如"眼镜店管理系统"
   - **Public/Private**：选择 **Public**（公开，Render免费层需要公开仓库）
   - 不要勾选 "Add a README file"、"Add .gitignore"、"Choose a license"
3. 点击底部绿色按钮 "Create repository"
4. 创建成功后，你会看到一个页面，上面有你的仓库地址，类似：
   `https://github.com/你的用户名/glasses-shop-system.git`
   **把这个地址记下来，后面要用**

### 3.4 上传代码到 GitHub

1. 打开项目文件夹 `glasses-shop-system`
2. 在文件夹地址栏输入 `cmd` 回车，打开命令行
3. 依次输入以下命令（每输入一行按一次回车）：

   ```
   git init
   ```

   ```
   git add .
   ```

   ```
   git commit -m "眼镜店管理系统初始版本"
   ```

   ```
   git branch -M main
   ```

   ```
   git remote add origin https://github.com/你的用户名/glasses-shop-system.git
   ```
   > ⚠️ 把上面的地址替换成你 3.3 步骤中记下的仓库地址！

   ```
   git push -u origin main
   ```

4. 如果是第一次使用 Git，可能会提示你设置用户名和邮箱，按提示输入：
   ```
   git config --global user.name "你的GitHub用户名"
   git config --global user.email "你的注册邮箱"
   ```
   然后重新执行 `git commit` 和 `git push` 命令。

5. 上传成功后，刷新 GitHub 仓库页面，就能看到你的代码了。

> 💡 **以后修改了代码，只需要在项目目录执行这三行就能更新：**
> ```
> git add .
> git commit -m "更新说明"
> git push
> ```

## 四、部署到 Render 云服务器

Render 是一个免费的云托管平台，可以把你的系统部署到互联网上，两个门店都能访问。

### 4.1 注册 Render 账号

1. 访问 https://render.com/
2. 点击右上角 "Get Started" 或 "Sign Up"
3. 选择 **"Sign up with GitHub"**（用 GitHub 账号登录，这样方便连接仓库）
4. 授权 Render 访问你的 GitHub 账号
5. 完成注册

### 4.2 创建 Web Service

1. 登录 Render 后，点击右上角的 **"New +"** 按钮
2. 选择 **"Web Service"**
3. 在仓库列表中找到你刚才创建的 `glasses-shop-system` 仓库，点击右边的 **"Connect"** 按钮
   - 如果看不到仓库，点击 "Configure account" 授权 Render 访问你的仓库

### 4.3 配置部署参数

进入配置页面后，填写以下信息：

| 配置项 | 填写内容 |
|--------|----------|
| **Name** | 给你的服务起个名字，比如 `glasses-shop`（这个名字会成为网址的一部分，只能用小写字母和数字） |
| **Region** | 选择 `Singapore`（新加坡，离中国近，访问速度快） |
| **Branch** | `main`（默认即可） |
| **Runtime** | `Node`（默认即可） |
| **Build Command** | `npm install` |
| **Start Command** | `npm start` |
| **Instance Type** | 选择 **Free**（免费版） |

> ⚠️ **重要**：免费版有以下限制，需要了解：
> - 15分钟没有访问会自动休眠，下次打开需要等 30-60 秒唤醒
> - 每月有 750 小时的免费额度（足够两个店正常使用）
> - 数据库文件存在 Render 的临时磁盘上，**重启后数据会丢失**！
>
> 💡 **解决方案**：系统已内置每天自动备份功能，你也可以随时在"系统设置"中手动下载备份。如果需要数据持久化，建议升级到 Render 付费版（约 $7/月），或者使用其他支持持久化存储的平台。

### 4.4 开始部署

1. 确认所有配置正确后，点击页面底部的 **"Create Web Service"** 按钮
2. Render 会开始拉取代码、安装依赖、启动服务，这个过程大约需要 2-5 分钟
3. 你会看到实时的部署日志，当日志中出现 `Your service is live 🎉` 或者类似 `listening on port 10000` 的信息，说明部署成功

### 4.5 访问系统

1. 部署成功后，在 Render 服务页面的顶部可以看到你的服务地址，类似：
   `https://glasses-shop.onrender.com`
2. 点击这个地址，就能在浏览器中打开系统了
3. **第一次打开可能需要等 30-60 秒**，因为免费版服务在休眠，需要唤醒。系统会显示友好的加载提示，请耐心等待。

### 4.6 配置前端地址

部署成功后，需要把前端代码中的服务器地址更新为你的 Render 地址：

1. 打开项目文件夹中的 `public/js/app.js` 文件
2. 找到第 14 行左右的 `API_BASE` 配置
3. 实际上代码已经做了自动检测：如果通过浏览器访问 Render 地址，会自动使用当前域名作为 API 地址，**不需要手动修改**。
4. 如果你使用 Electron 桌面客户端，需要修改 `electron/main.js` 中的 `SERVER_URL` 为你的 Render 地址（见第五章）。

## 五、打包桌面客户端（Electron）

虽然系统可以直接在浏览器中使用，但打包成桌面 .exe 程序更方便门店日常使用，双击图标就能打开。

### 5.1 修改服务器地址

1. 打开 `electron/main.js` 文件
2. 找到第 13 行：
   ```javascript
   const SERVER_URL = 'https://your-app.onrender.com';
   ```
3. 把 `https://your-app.onrender.com` 替换成你在第四章部署成功后得到的 Render 地址，比如：
   ```javascript
   const SERVER_URL = 'https://glasses-shop.onrender.com';
   ```
4. 保存文件

### 5.2 安装 Electron 依赖

1. 打开 `electron` 文件夹
2. 在地址栏输入 `cmd` 回车，打开命令行
3. 输入以下命令安装依赖：
   ```
   npm install
   ```
   这个过程需要下载 Electron，文件较大（约 100MB），可能需要 5-10 分钟，请耐心等待。

### 5.3 测试运行

安装完成后，可以先测试一下能否正常运行：

```
npm start
```

如果弹出一个窗口，加载出眼镜店管理系统，说明配置正确。关闭窗口即可。

### 5.4 打包成 .exe 安装包

1. 在 `electron` 文件夹的命令行中输入：
   ```
   npm run dist:win
   ```
2. 打包过程需要 2-5 分钟，完成后会在 `electron/dist/` 目录下生成安装包
3. 生成的文件：
   - `眼镜店管理系统 Setup 1.0.0.exe` — 安装包（推荐，双击安装后在桌面和开始菜单生成快捷方式）
   - `win-unpacked/` 文件夹 — 免安装版，直接运行里面的 `眼镜店管理系统.exe` 即可

### 5.5 分发到两个门店

1. 把生成的 `.exe` 安装包通过 U 盘、微信、QQ 等方式传到两个门店的电脑上
2. 每台电脑双击安装包，一路"下一步"完成安装
3. 安装完成后，桌面会出现"眼镜店管理系统"图标，双击即可使用
4. 两个门店的数据都存在同一个 Render 服务器上，**实时共享**

> 💡 **可选：生成便携版**
> 如果不想安装，可以运行 `npm run dist:win-portable`，生成一个单文件的便携版 `.exe`，拷贝到任何电脑都能直接运行，不需要安装。

## 六、两店数据共享说明

本系统的核心优势就是支持两个门店数据实时共享，原理如下：

```
┌─────────────┐         ┌──────────────────┐         ┌─────────────┐
│  门店A电脑   │  ────→  │  Render 云服务器  │  ←────  │  门店B电脑   │
│ (浏览器/EXE) │         │  (同一数据库)     │         │ (浏览器/EXE) │
└─────────────┘         └──────────────────┘         └─────────────┘
```

- 所有数据（会员、库存、订单、验光）都存储在 Render 服务器的同一个数据库中
- 门店A新增的会员，门店B刷新页面后立即能看到
- 门店A销售商品扣减了库存，门店B的库存也会同步减少
- 两个门店的验光记录、订单记录都在一起，可以互相查看

### 使用建议

1. **门店标识**：在收银和验光时，可以在"门店"字段填写具体门店名称（如"总店"、"分店"），方便后续统计各店业绩
2. **操作员**：建议在"操作员"字段填写具体操作人员姓名，方便追溯
3. **网络要求**：两个门店的电脑都需要能上网，建议使用稳定的宽带网络
4. **数据刷新**：如果另一店刚做了操作，当前页面可能需要手动刷新（按 F5）才能看到最新数据

## 七、数据备份与安全

### 7.1 自动备份

系统已内置自动备份功能：
- 每天凌晨 2:00 自动备份所有数据到服务器的 `data/backups/` 目录
- 自动保留最近 30 天的备份，更早的自动清理

### 7.2 手动备份

强烈建议定期手动下载备份文件，保存在本地：

1. 登录系统，点击左侧菜单的 **"系统设置"**
2. 找到 **"下载数据备份"**，点击 **"📥 下载备份"** 按钮
3. 浏览器会下载一个 JSON 文件，文件名类似 `glasses_shop_backup_2026-09-05.json`
4. 把这个文件保存在安全的地方（比如 U 盘、云盘）
5. **建议每周至少备份一次**，重要操作前后都备份一次

### 7.3 数据恢复

如果需要恢复数据（比如换服务器、误删数据）：

1. 在"系统设置"页面找到 **"导入数据备份"**
2. 点击 **"📤 导入备份"** 按钮
3. 选择之前下载的 JSON 备份文件
4. 确认导入（⚠️ 会覆盖当前所有数据，请谨慎操作）
5. 导入成功后系统会自动刷新

### 7.4 Render 免费版数据安全提醒

⚠️ **Render 免费版的磁盘是临时的**，服务重启或重新部署后，数据库文件可能会丢失。因此：

- **务必定期手动下载备份**（每周至少一次）
- 不要在 Render 免费版上存储唯一的重要数据
- 如果业务数据非常重要，建议：
  - 升级 Render 付费版（$7/月，支持持久化磁盘）
  - 或使用其他支持持久化存储的平台（如 Railway、Fly.io、阿里云等）
  - 或自己购买一台云服务器（阿里云/腾讯云轻量应用服务器，约 50-100 元/月）

## 八、常见问题解答

### Q1: 打开系统显示"正在连接服务器"一直转怎么办？

**A:** Render 免费版 15 分钟无访问会休眠，首次打开需要 30-60 秒唤醒。请耐心等待。如果超过 2 分钟还没打开，可能是：
- 网络问题，检查电脑是否能上网
- Render 服务出问题了，登录 Render 后台查看服务状态
- 服务地址写错了，检查地址是否正确

### Q2: 两个门店能同时使用吗？会不会冲突？

**A:** 可以同时使用，系统支持多人同时在线操作。数据库有事务保护，不会出现数据冲突。但建议两个门店不要同时对同一个会员进行充值或消费操作。

### Q3: 能在手机上使用吗？

**A:** 可以，系统做了响应式适配，手机浏览器访问 Render 地址也能使用。但收银和验光操作建议在电脑上进行，屏幕大操作方便。

### Q4: 验光报告单怎么打印？

**A:** 在"验光管理"页面，找到对应的验光记录，点击"打印"按钮，会弹出打印预览，选择打印机即可打印。报告单是黑白样式，适合普通打印机。

### Q5: 会员余额支付怎么用？

**A:** 首先需要在"会员管理"中给会员充值。然后在"消费收银"页面，搜索并选择该会员，选择商品后，支付方式选"余额支付"，确认收款后会自动从会员余额中扣减。

### Q6: 订单退款后库存和余额会恢复吗？

**A:** 会的。在"订单记录"中点击"退款删除"，系统会自动：
- 把商品库存加回去
- 如果是余额支付，把钱退回到会员余额
- 删除订单记录

### Q7: 怎么修改门店名称和联系方式？

**A:** 在"系统设置"页面的"门店信息"中修改，保存后侧边栏和验光报告单上的门店信息会自动更新。

### Q8: npm install 报错怎么办？

**A:** 常见原因和解决方法：
- **网络问题**：切换网络，或者使用国内镜像。在命令行执行：
  ```
  npm config set registry https://registry.npmmirror.com
  ```
  然后重新执行 `npm install`
- **Node 版本太低**：升级到 Node.js 18 或更高版本
- **权限问题**：右键命令行，选择"以管理员身份运行"

### Q9: Electron 打包失败怎么办？

**A:** 常见原因：
- **网络问题**：Electron 打包需要下载一些文件，网络不好会失败。可以设置国内镜像：
  ```
  set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
  set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
  ```
  然后重新打包
- **杀毒软件拦截**：暂时关闭杀毒软件后再打包
- **路径有中文**：确保项目路径中没有中文字符

### Q10: 数据存在 Render 上安全吗？会不会被别人看到？

**A:** Render 服务默认是公开可访问的（只要知道网址就能打开）。目前系统没有登录密码功能，如果需要限制访问，可以：
- 在 Render 后台设置环境变量，添加简单的密码验证
- 或者只把网址告诉两个门店的工作人员，不对外公开
- 重要数据定期备份到本地
